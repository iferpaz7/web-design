## Actividad de la clase: Clínica de optimización de conversión

Revisa la página web que publicaste o dejaste compartible en la unidad anterior. El objetivo no es rehacerla completa, sino detectar oportunidades concretas para que el usuario comprenda mejor la propuesta y avance con menos fricción hacia la acción esperada.

1. **URL y objetivo de conversión:** escribe el enlace de tu página y define cuál es la acción principal esperada del usuario: contacto, registro, compra, reserva, descarga, solicitud de información u otra.
2. **Tres oportunidades de mejora:** identifica una oportunidad relacionada con claridad del mensaje, una relacionada con CTA o ruta de contacto, y una relacionada con confianza, legibilidad, accesibilidad o experiencia móvil.
3. **Tipo de fricción:** clasifica cada oportunidad como fricción funcional, cognitiva o emocional.
4. **Priorización:** ordena las tres oportunidades con una matriz impacto-esfuerzo y selecciona la mejora número uno.
5. **Hipótesis de mejora:** redacta una frase con esta estructura: "Si cambio..., entonces el usuario podrá..., porque...".
6. **Retroalimentación docente:** comparte tu hipótesis prioritaria con el docente, incorpora la observación recibida y define qué ajuste implementarás antes de la siguiente sesión.

## Evidencia esperada

Entrega un documento breve con la URL de tu página, las tres oportunidades priorizadas, la clasificación de fricción, la hipótesis de mejora validada y el ajuste que implementarás.

**Criterios:**

- La observación se basa en una página real publicada o compartible.
- Las oportunidades están conectadas con claridad, CTA, confianza, accesibilidad, rendimiento o experiencia móvil.
- La priorización usa una lógica impacto-esfuerzo comprensible.
- La hipótesis relaciona un cambio concreto con una acción esperada del usuario.
- La entrega incorpora la retroalimentación recibida en clase.
