# U1 / Tema 4: Usabilidad, accesibilidad y lectura móvil

**Diseño Web para Marketing Digital | Sesión del 14 de mayo de 2026 | Ing. Ivan Paz**

**Objetivo de la clase:** 
Aplicar criterios básicos de usabilidad web y accesibilidad, evaluando lectura y navegación "Mobile-First", elaborando y utilizando una lista de cotejo que asegure que todos nuestros usuarios recorran nuestro sitio sin fricción tecnológica.
