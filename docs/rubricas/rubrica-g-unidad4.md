# Rúbrica G — Optimización, medición y sustentación (Unidad 4)

**Aplica a:**

- Actividad: SEO y rendimiento (U4T1) — avance Proyecto 40 %
- Actividad: Medición básica (U4T2) — avance Proyecto 40 %
- Actividad: Ensayo de sustentación y reporte (U4T3) — cierre Proyecto 40 %

**Puntaje máximo:** 10 puntos (4 criterios × máximo 2.5 pts)

---

## Criterios y niveles

### Criterio 1 — Ajustes aplicados con evidencia (2.5 pts máx)

| Nivel         | Descripción                                                                                                              | Puntos |
| ------------- | ------------------------------------------------------------------------------------------------------------------------ | ------ |
| Excelente     | Al menos 3 ajustes (title, meta, encabezados, alt, rendimiento) aplicados en el constructor, con capturas antes/después. | 2.5    |
| Satisfactorio | 3 ajustes aplicados pero evidencia incompleta (falta un antes/después).                                                  | 1.75   |
| En desarrollo | Menos de 3 ajustes o solo descritos, sin aplicar.                                                                        | 1.0    |
| Insuficiente  | Sin ajustes ni evidencia.                                                                                                | 0      |

### Criterio 2 — Medición honesta (2.5 pts máx)

| Nivel         | Descripción                                                                                                                              | Puntos |
| ------------- | ---------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Excelente     | Matriz dato→hallazgo→hipótesis→mejora→verificación con fuente, periodo y límites declarados; sin causalidad afirmada con datos pequeños. | 2.5    |
| Satisfactorio | Matriz completa pero límites poco explicitados.                                                                                          | 1.75   |
| En desarrollo | Dato sin fuente ni periodo, o hallazgo que afirma causas no sostenidas.                                                                  | 1.0    |
| Insuficiente  | Cifras inventadas o sin captura/fuente; la entrega queda invalidada.                                                                     | 0      |

### Criterio 3 — Sustentación (2.5 pts máx)

| Nivel         | Descripción                                                                                                      | Puntos |
| ------------- | ---------------------------------------------------------------------------------------------------------------- | ------ |
| Excelente     | Guion de 5 partes en lenguaje de objetivos (≤4 min), cada mejora con evidencia, preguntas incómodas anticipadas. | 2.5    |
| Satisfactorio | Estructura completa pero con jerga sin traducir o una evidencia débil.                                           | 1.75   |
| En desarrollo | Guion descriptivo (pantalla por pantalla) sin argumentación de decisiones.                                       | 1.0    |
| Insuficiente  | Sin guion ni presentación (en vivo o video de 4 min).                                                            | 0      |

### Criterio 4 — Cierre profesional (2.5 pts máx)

| Nivel         | Descripción                                                                                                 | Puntos |
| ------------- | ----------------------------------------------------------------------------------------------------------- | ------ |
| Excelente     | Reporte ejecutivo con decisiones, impacto y próximo paso; URL final + lista de cotejo + hipótesis cerradas. | 2.5    |
| Satisfactorio | Reporte completo pero con un componente superficial (impacto o próximo paso).                               | 1.75   |
| En desarrollo | Reporte parcial o URL final desactualizada respecto a lo sustentado.                                        | 1.0    |
| Insuficiente  | Sin reporte ni URL final.                                                                                   | 0      |

---

## Notas

- Toda cifra exige captura + URL + periodo. Prohibido inventar métricas.
- Si se usó IA, declarar `Borrador IA: [modelo] / Versión final propia: [qué cambié]`; la IA no presenta por el estudiante.
- Ver guía APA: `docs/guia-apa-estudiante.md`.
