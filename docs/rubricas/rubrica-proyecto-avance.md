# Rúbrica C — Proyecto integrador (avance por entrega)

**Aplica a:**
- Actividad: Mapa de secciones guiado (U2T2) — avance Proyecto 40 %
- Actividad: Copy persuasivo para tu proyecto (U2T3) — avance Proyecto 40 %

**Puntaje máximo:** 10 puntos (4 criterios × máximo 2.5 pts)

---

## Criterios y niveles

### Criterio 1 — Pertinencia estratégica (2.5 pts máx)

| Nivel | Descripción | Puntos |
|---|---|---|
| Excelente | El entregable responde directamente al perfil de usuario, objetivo de campaña y mensaje central definidos en el proyecto integrador. | 2.5 |
| Satisfactorio | Responde al proyecto pero con desfases menores respecto al perfil de usuario o al mensaje central previo. | 1.75 |
| En desarrollo | El entregable está desconectado del perfil de usuario o del objetivo de campaña del proyecto. | 1.0 |
| Insuficiente | No guarda relación con el proyecto integrador del estudiante; podría corresponder a cualquier proyecto genérico. | 0 |

### Criterio 2 — Aplicación correcta de la estructura o fórmula del tema (2.5 pts máx)

| Nivel | Descripción | Puntos |
|---|---|---|
| Excelente | Aplica correctamente los modelos del tema (bloques funcionales + AIDA/PAS, fórmula titular + beneficios + CTA, etc.) sin omisiones ni errores conceptuales. | 2.5 |
| Satisfactorio | Aplica la estructura con uno o dos errores o elementos faltantes que no afectan la coherencia general. | 1.75 |
| En desarrollo | La estructura está parcialmente aplicada; faltan elementos clave o se aplican de forma incorrecta. | 1.0 |
| Insuficiente | No aplica la estructura del tema; el entregable no tiene un modelo reconocible. | 0 |

### Criterio 3 — Claridad y especificidad del contenido (2.5 pts máx)

| Nivel | Descripción | Puntos |
|---|---|---|
| Excelente | Cada elemento (sección, beneficio, CTA, etc.) tiene un propósito específico y verificable; no hay elementos vagos o genéricos. | 2.5 |
| Satisfactorio | La mayoría de los elementos son específicos pero uno o dos son genéricos o poco desarrollados. | 1.75 |
| En desarrollo | Varios elementos son vagos o intercambiables; no reflejan el proyecto concreto del estudiante. | 1.0 |
| Insuficiente | Los elementos son genéricos en su totalidad; no reflejan ningún proyecto específico. | 0 |

### Criterio 4 — Calidad de la redacción y presentación (2.5 pts máx)

| Nivel | Descripción | Puntos |
|---|---|---|
| Excelente | La redacción es clara, breve y escaneable; el formato facilita la lectura y la revisión; sin errores ortográficos relevantes. | 2.5 |
| Satisfactorio | La redacción es comprensible pero con algunas redundancias, párrafos innecesarios o inconsistencias de formato. | 1.75 |
| En desarrollo | La redacción dificulta la comprensión o el formato hace difícil identificar los elementos evaluados. | 1.0 |
| Insuficiente | La redacción es confusa o el entregable no tiene una presentación legible. | 0 |
