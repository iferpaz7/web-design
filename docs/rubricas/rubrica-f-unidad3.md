# Rúbrica F — Producción y publicación (Unidad 3)

**Aplica a:**

- Actividad: Plan de implementación (U3T1) — avance Proyecto 40 %
- Actividad: Maquetación responsive (U3T2) — avance Proyecto 40 %
- Actividad: Formulario y conversión (U3T3) — avance Proyecto 40 %
- Actividad: Auditoría integral de calidad y conversión (U3T4) — cierre Proyecto 40 % U3 + apertura U4

**Puntaje máximo:** 10 puntos (4 criterios × máximo 2.5 pts)

---

## Criterios y niveles

### Criterio 1 — Decisión y ejecución justificada (2.5 pts máx)

| Nivel         | Descripción                                                                                                                  | Puntos |
| ------------- | ---------------------------------------------------------------------------------------------------------------------------- | ------ |
| Excelente     | La elección de herramienta se justifica con criterios (tiempo, control, formularios, SEO, costo) y la ejecución los refleja. | 2.5    |
| Satisfactorio | Hay justificación pero genérica, o la ejecución se desvía en un aspecto menor de lo decidido.                                | 1.75   |
| En desarrollo | La herramienta se eligió sin criterios explícitos; la ejecución parece improvisada.                                          | 1.0    |
| Insuficiente  | Sin decisión declarada ni ejecución verificable (sin URL ni capturas).                                                       | 0      |

### Criterio 2 — Funcionamiento real (2.5 pts máx)

| Nivel         | Descripción                                                                                                | Puntos |
| ------------- | ---------------------------------------------------------------------------------------------------------- | ------ |
| Excelente     | URL pública verificable: sin enlaces rotos, formulario con envío y confirmación probados, carga aceptable. | 2.5    |
| Satisfactorio | Funciona con un hallazgo menor documentado (p. ej. un ajuste de carga pendiente).                          | 1.75   |
| En desarrollo | Fallas funcionales sin corregir (enlace roto, formulario sin probar, versión móvil rota).                  | 1.0    |
| Insuficiente  | Página no publicada o no compartible; sin evidencia de funcionamiento.                                     | 0      |

### Criterio 3 — Calidad y accesibilidad básica (2.5 pts máx)

| Nivel         | Descripción                                                                                                     | Puntos |
| ------------- | --------------------------------------------------------------------------------------------------------------- | ------ |
| Excelente     | Lista de cotejo completa + WAVE y PageSpeed ejecutados, con al menos dos correcciones aplicadas y documentadas. | 2.5    |
| Satisfactorio | Auditoría ejecutada pero con una corrección pendiente debidamente registrada.                                   | 1.75   |
| En desarrollo | Auditoría incompleta (falta una herramienta o la lista de cotejo).                                              | 1.0    |
| Insuficiente  | Sin auditoría ni lista de cotejo.                                                                               | 0      |

### Criterio 4 — Hipótesis de mejora (2.5 pts máx)

| Nivel         | Descripción                                                                                                                                 | Puntos |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Excelente     | Tres oportunidades priorizadas con matriz impacto-esfuerzo e hipótesis "Si cambio…, entonces…, porque…" validada, sobre acción del usuario. | 2.5    |
| Satisfactorio | Hipótesis válida pero priorización débil o sin validación docente registrada.                                                               | 1.75   |
| En desarrollo | Oportunidades genéricas sin clasificar ni priorizar; hipótesis sobre estética, no sobre acción.                                             | 1.0    |
| Insuficiente  | Sin oportunidades ni hipótesis.                                                                                                             | 0      |

---

## Notas

- Toda cifra (PageSpeed, WAVE) exige captura + URL + fecha. Las cifras inventadas invalidan la entrega.
- Si se usó IA, declarar `Borrador IA: [modelo] / Versión final propia: [qué cambié]`; la entrega final pegada de IA no se acepta.
- Ver guía APA: `docs/guia-apa-estudiante.md`.
