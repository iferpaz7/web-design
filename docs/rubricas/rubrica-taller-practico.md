# Rúbrica B — Taller práctico en clase

**Aplica a:**

- Actividad: Brief inicial de campaña (U1T1)
- Actividad: Rediseño guiado del hero (U1T3)
- Actividad: Ficha de usuario y mensaje central (U2T1)

**Puntaje máximo:** 10 puntos (4 criterios × máximo 2.5 pts)

---

## Criterios y niveles

### Criterio 1 — Completitud del entregable (2.5 pts máx)

| Nivel         | Descripción                                                                                | Puntos |
| ------------- | ------------------------------------------------------------------------------------------ | ------ |
| Excelente     | El entregable incluye todos los elementos solicitados en las instrucciones, sin excepción. | 2.5    |
| Satisfactorio | Falta un elemento menor o está incompleto pero el entregable es funcional.                 | 1.75   |
| En desarrollo | Faltan dos o más elementos solicitados; el entregable está incompleto.                     | 1.0    |
| Insuficiente  | El entregable no responde a las instrucciones o está en blanco.                            | 0      |

### Criterio 2 — Precisión y especificidad (2.5 pts máx)

| Nivel         | Descripción                                                                                        | Puntos |
| ------------- | -------------------------------------------------------------------------------------------------- | ------ |
| Excelente     | Los elementos son concretos, específicos y verificables; evita respuestas genéricas o vagas.       | 2.5    |
| Satisfactorio | La mayoría de los elementos son específicos pero alguno es genérico o ambiguo.                     | 1.75   |
| En desarrollo | Los elementos son mayormente genéricos; no permiten distinguir el caso de proyecto del estudiante. | 1.0    |
| Insuficiente  | Las respuestas son genéricas o irrelevantes para el proyecto personal del estudiante.              | 0      |

### Criterio 3 — Aplicación de criterios del tema (2.5 pts máx)

| Nivel         | Descripción                                                                                                                            | Puntos |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Excelente     | Aplica correctamente las fórmulas, estructuras o criterios del tema vistos en clase (brief, ficha de usuario, jerarquía visual, etc.). | 2.5    |
| Satisfactorio | Aplica los criterios del tema con errores menores o de forma incompleta.                                                               | 1.75   |
| En desarrollo | El entregable existe pero no sigue la estructura ni los criterios del tema.                                                            | 1.0    |
| Insuficiente  | No aplica ningún criterio del tema; la entrega es improvisada o sin base conceptual.                                                   | 0      |

### Criterio 4 — Coherencia interna (2.5 pts máx)

| Nivel         | Descripción                                                                                                                                        | Puntos |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Excelente     | Los elementos del entregable son coherentes entre sí; objetivo, público y acción (o perfil, necesidad y mensaje) se articulan sin contradicciones. | 2.5    |
| Satisfactorio | Hay coherencia general pero algún elemento no encaja bien con los demás.                                                                           | 1.75   |
| En desarrollo | Hay contradicciones notables entre los elementos del entregable.                                                                                   | 1.0    |
| Insuficiente  | El entregable carece de coherencia interna o sus elementos son incompatibles.                                                                      | 0      |
