# Rúbrica D — Proyecto integrador (entregable de cierre de unidad)

**Aplica a:**
- Actividad: Prototipo navegable de tu página de campaña (U2T4) — Proyecto 40 %

**Puntaje máximo:** 10 puntos (4 criterios × máximo 2.5 pts)

---

## Criterios y niveles

### Criterio 1 — Completitud del prototipo (2.5 pts máx)

| Nivel | Descripción | Puntos |
|---|---|---|
| Excelente | El prototipo incluye hero con titular y CTA, sección de beneficios, prueba social o validación, segundo CTA antes del footer, y vistas móvil (375 px) y escritorio (1440 px). | 2.5 |
| Satisfactorio | Incluye la mayoría de los elementos obligatorios pero falta uno menor (ej. solo una vista o falta la prueba social). | 1.75 |
| En desarrollo | Faltan dos o más elementos obligatorios; el prototipo es claramente incompleto. | 1.0 |
| Insuficiente | El prototipo no incluye los elementos mínimos evaluables o no existe entregable. | 0 |

### Criterio 2 — Flujo navegable hero → CTA → destino (2.5 pts máx)

| Nivel | Descripción | Puntos |
|---|---|---|
| Excelente | El CTA del hero conecta con el formulario o pantalla de contacto mediante interacción básica; el recorrido funciona sin confusión. | 2.5 |
| Satisfactorio | El flujo existe pero tiene una interrupción menor (ej. el CTA está presente pero no conectado, o el destino está indicado sin interacción). | 1.75 |
| En desarrollo | El flujo es incompleto o confuso; el usuario no puede seguir el recorrido sin adivinar. | 1.0 |
| Insuficiente | No hay flujo navegable; el prototipo es solo una imagen estática sin recorrido indicado. | 0 |

### Criterio 3 — Coherencia con el proyecto integrador (2.5 pts máx)

| Nivel | Descripción | Puntos |
|---|---|---|
| Excelente | El prototipo refleja fielmente el mapa de secciones (U2T2) y el copy (U2T3); los elementos visuales corresponden a las decisiones previas del proyecto. | 2.5 |
| Satisfactorio | El prototipo sigue el proyecto integrador con desfases menores (ej. alguna sección reordenada o un copy diferente al entregado). | 1.75 |
| En desarrollo | El prototipo no sigue el mapa de secciones ni el copy del proyecto; parece un diseño diferente. | 1.0 |
| Insuficiente | El prototipo no guarda relación con las entregas previas del proyecto integrador. | 0 |

### Criterio 4 — Nota de validación con criterio propio (2.5 pts máx)

| Nivel | Descripción | Puntos |
|---|---|---|
| Excelente | La nota describe qué confirmó el prototipo sobre el recorrido del usuario, menciona al menos un ajuste realizado y muestra criterio propio (no solo describe lo que hizo). | 2.5 |
| Satisfactorio | La nota está presente y menciona un ajuste, pero es descriptiva más que reflexiva. | 1.75 |
| En desarrollo | La nota existe pero es muy superficial ("todo quedó bien") o no menciona ningún ajuste. | 1.0 |
| Insuficiente | No hay nota de validación. | 0 |
