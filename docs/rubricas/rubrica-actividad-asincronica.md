# Rúbrica E — Actividad asincrónica (HAA)

**Aplica a:**

- Actividad: Auditoría visual comparativa (U1T3 — asincrónica)
- Actividad: Análisis de páginas de referencia (U2T1 — asincrónica)

**Puntaje máximo:** 10 puntos (4 criterios × máximo 2.5 pts)

---

## Criterios y niveles

### Criterio 1 — Identificación del usuario, problema o mensaje implícito (2.5 pts máx)

| Nivel         | Descripción                                                                                                                                                      | Puntos |
| ------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Excelente     | Describe con precisión el usuario implícito o el problema central de la página analizada; la descripción es específica y refleja lectura cuidadosa de la página. | 2.5    |
| Satisfactorio | La descripción es pertinente pero superficial o poco diferenciada del caso analizado.                                                                            | 1.75   |
| En desarrollo | La descripción es genérica y podría aplicar a cualquier página del sector.                                                                                       | 1.0    |
| Insuficiente  | No identifica usuario, problema ni mensaje central, o la respuesta está en blanco.                                                                               | 0      |

### Criterio 2 — Análisis con evidencia concreta (2.5 pts máx)

| Nivel         | Descripción                                                                                                                                                           | Puntos |
| ------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Excelente     | El análisis se ancla en elementos concretos de la página (texto del titular, posición del CTA, colores, etc.); no describe de memoria sino de la observación directa. | 2.5    |
| Satisfactorio | El análisis menciona elementos de la página pero sin especificar cómo o dónde aparecen.                                                                               | 1.75   |
| En desarrollo | El análisis es especulativo o no se basa en elementos observables de la página.                                                                                       | 1.0    |
| Insuficiente  | No hay análisis; solo hay descripción o transcripción del contenido de la página.                                                                                     | 0      |

### Criterio 3 — Respaldo bibliográfico institucional (2.5 pts máx)

| Nivel         | Descripción                                                                                                                                                                                                                                                     | Puntos |
| ------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Excelente     | Cita al menos una fuente de la biblioteca UNACH (eLibro, VuFind, Digitalia u otra base institucional) pertinente al tema analizado, en formato APA 7.ª edición o con referencia verificable. La fuente sustenta directamente el análisis o la mejora propuesta. | 2.5    |
| Satisfactorio | Cita una fuente institucional UNACH pero la conexión con el análisis es débil, o la referencia está incompleta aunque sea verificable.                                                                                                                          | 1.75   |
| En desarrollo | Cita una fuente externa no institucional (sitio web, blog, video) como único respaldo, sin recurrir a la biblioteca UNACH.                                                                                                                                      | 1.0    |
| Insuficiente  | No cita ninguna fuente o la fuente citada no existe o no es verificable.                                                                                                                                                                                        | 0      |

### Criterio 4 — Entrega y formato (2.5 pts máx)

| Nivel         | Descripción                                                                                                            | Puntos |
| ------------- | ---------------------------------------------------------------------------------------------------------------------- | ------ |
| Excelente     | Entregada antes de la próxima sesión sincrónica; responde los cuatro puntos solicitados con claridad y sin ambigüedad. | 2.5    |
| Satisfactorio | Entregada a tiempo pero falta algún punto o la respuesta a alguno es muy breve.                                        | 1.75   |
| En desarrollo | Entregada con retraso o faltan dos o más puntos solicitados.                                                           | 1.0    |
| Insuficiente  | No entregada o entregada vacía.                                                                                        | 0      |
